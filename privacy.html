Privacy Policy

Last updated: October 20, 2026

BOXSCORE's publishing tool is an internal tool used only by the channel owner (the "Operator"). It is not offered to other users.

1. Data we access

TikTok. When the account owner connects the TikTok account with Login Kit, the tool receives an access token, the account's open ID, display name and avatar (user.info.basic). It uses the token only to upload and publish the owner's own videos (video.upload, video.publish).

YouTube. The tool uses the YouTube API Services. With the owner's authorization (Google OAuth), it uploads videos to the owner's own YouTube channels, sets titles, descriptions and thumbnails, reads view, like and comment statistics of the owner's own videos, and likes or replies to comments on those videos. It also runs keyword searches of public YouTube videos for content planning. Public comment text and commenter display names on the owner's videos are read only to reply to them.

Instagram. The tool uses the Instagram API with Instagram Login only for the Operator's own Instagram professional accounts (@geoul_item, @gigi_pick_, @boxscore_kr). It reads the account's profile and media (instagram_business_basic) and publishes the owner's own posts (instagram_business_content_publish). When a viewer leaves a comment containing a keyword such as "목록" ("list") under one of the owner's posts, the tool reads that comment (instagram_business_manage_comments) and sends that viewer exactly one private reply with the product list and a link they asked for (instagram_business_manage_messages). It reads only comments on the owner's own media and never sends unsolicited or bulk messages.

2. How we use it

Data is used only to show the connected account and to publish the owner's videos. We do not sell, share or disclose it to third parties, and we do not use it for advertising or profiling. Instagram comment data is used only to detect the requested keyword and send the single reply the commenter asked for.

3. Storage

The access token is stored only on the Operator's own computer. We do not collect data from other TikTok users or viewers. For Instagram, the tool keeps only the comment ID, the commenter's username and the time a reply was sent, so that the same person is not messaged twice.

4. Retention and deletion

The owner can disconnect at any time by removing the app in TikTok (Settings and privacy → Security & permissions → Apps and websites) and by deleting the stored token from the computer. YouTube access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. Statistics of the owner's own videos are stored on the Operator's computer to compare performance over time; no data about other YouTube users is kept beyond replying to their comments. Instagram comment records (comment ID, username, time) are deleted automatically after 30 days. Instagram users can request deletion of their data at any time — see Data Deletion Instructions. Contact us to request deletion.

5. YouTube and Google policies

By using the YouTube features of this tool you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. This tool does not use cookies or place any tracking on users' devices.
